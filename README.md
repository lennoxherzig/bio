# MrPiesel bio

Next.js clone of [guns.lol/mrpiesel](https://guns.lol/mrpiesel).

## Media

Put files in `public/Media/`:

| File | What it does |
| --- | --- |
| `Background.mp4` | Video background (wins if both exist) |
| `Background.png` | Image background |
| `sound.mp3` | Audio that starts after click-to-enter |
| `Avatar.png` | Optional profile picture |

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
